# WorldWeaver Lib — Generate Custom Biomes and Structures

WorldWeaver Lib 9minecraft Mod works behind the scenes to help other mods build new worlds. It handles the complicated math and coding for world generation so other addons can run without issues. This mod does not add any items, blocks, or mobs for you to play with directly. Instead, you install it only when another mod lists it as a requirement. It provides the core code for the BetterX family of mods, like their main library and nether overhaul, allowing them to place custom biomes and structures in your game.

## What this build is

An unofficial rebuild of **Frank**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
